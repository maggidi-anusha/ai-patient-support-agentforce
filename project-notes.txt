AI Patient Support & Medical Report Simplifier | Salesforce + Apex + Gemini API

• Developed a Salesforce-based patient support application that simplifies medical report text, classifies urgency and suggests next steps using the Gemini API.

• Integrated Google's Gemini API using Apex HTTP callouts through a Named Credential, with the API key stored in an encrypted External Credential.

• Improved AI consistency with explicit triage rules, JSON response mode and temperature 0.

• Built custom objects including Patient, Medical Report, and Appointment Request.

• Implemented urgency classification and automated appointment creation for critical cases.

• Designed reports, dashboards, and list views for monitoring patient data.

• Added duplicate prevention logic, exception handling, and 10 Apex unit tests with mocked callouts (98-100% coverage).

• Used Git, GitHub and the Salesforce CLI for version control and manifest-based deployment.
