****2-Minute Project Explanation

One of my projects is AI Patient Support & Medical Report Simplifier built on Salesforce.

The problem I wanted to solve was that medical reports are often difficult for patients to understand, and critical conditions may require immediate attention.

To solve this, I integrated Salesforce with Google's Gemini API using Apex HTTP callouts. When a Medical Report is created, the report text is sent to Gemini AI, which generates a simplified summary, determines the urgency level, and provides recommendations and disclaimers.

For high urgency cases, the system automatically creates an Appointment Request. I also built reports, dashboards, and list views for monitoring the data.

During development, I faced challenges such as JSON parsing issues, null pointer exceptions, and duplicate appointment creation. I solved these problems using exception handling, default values, and duplicate-check logic.

Through this project, I learned external API integration, Apex development, JSON parsing, testing, and Salesforce automation.
